# fields separated by |:
#
#   name | version | epoch | kind | source | pin | key file under keyring/extras | key fingerprint
#
# kind tarball: <source> is the URL of a release tarball, <pin> is sha256:<hash> of it, and the
#   tarball is fetched with <source>.asc, or <source minus .tar.xz>.tar.xz.asc, next to it, whose
#   signature has to verify against the key file and be made by that fingerprint.
# kind git: <source> is a repository, <pin> is <tag>=<commit>: the tag has to resolve to that
#   commit. The project signs neither, so what is trusted is the commit a reviewer read, and a
#   newer one is a pull request that changes this line.
#
