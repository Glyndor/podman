# The tooling each suite needs that the runner of ubuntu-26.04 does not have.
# Exact suite path followed by the tools; '-' explicitly needs no additions.
# Read from BASE. Missing or unknown suites and malformed entries install
# everything, so a new suite is not listed until its tools have been reviewed
# and therefore gets the full install automatically.
# No globs, inheritance or package groups.
#
# What is in it today:
#
#   mldsa-wheel   the virtual environment of the pinned cryptography wheel
#                 (.github/scripts/release/sign-requirements.txt), which the
#                 runner builds for the one suite that makes and verifies real
#                 ML-DSA-65 signatures. The wheel is installed only when a suite
#                 that needs it is among the ones the change can affect.
#
# Found by reading each suite and noting what it executes: the suites that read
# a workflow need PyYAML, which the runner image ships, and the suite that runs
# the linter needs shellcheck, which the job installs for itself.
